# Changelog

## 1.1.0

- Five saved animation styles: Connector, Screen Edge, Halo, Ripple, and Underline.
- Subtle full-screen edge trace with a dimmer reverse on unplug.
- Style selection in the main window and menu bar popover.
- Shared click-through overlay lifecycle, display-change cleanup, and Reduce Motion.
- Universal Apple silicon / Intel build and drag-to-Applications DMG packaging.
- Standalone open-source build scripts, MIT license, CI, and expanded tests.

## 1.0.0

- Native power monitoring, connector animation, optional sound, and menu bar battery percentage.
